AI COMMAND CENTER

A case study in agent orchestration: one request in, the right specialist on it, QA before anything ships.

WHAT IT DOES
  • Takes a request in plain English. An orchestrator agent triages it, sets a QA level and acceptance criteria, and routes it to the one specialist it needs.
  • Runs a team of ten AI specialists. WordPress, full-stack, design, project management, career/ATS, research, security, video and finance agents, each with its own rules and tools.
  • Gates every output. Nothing reaches me without a QA pass. High-risk work also needs a security review, loop budgets stop runaway retries, and live sites need my explicit approval.
  • Remembers across sessions. An Obsidian knowledge vault serves as long-term memory, so any session can resume a task from its card.
WHAT WE BUILT
  • The agent system: 10 Claude Code subagents and 15 skills, with governance rules enforced in code rather than left to prompts.
  • A shared state CLI that agents and the dashboard both use for tasks, QA results, security findings and the activity log.
  • A React + TypeScript dashboard with two themes: a sci-fi command HUD and a pixel-art town where each agent walks to the tasks it is working on.
  • A live 3D map of the knowledge vault (Three.js) showing notes, links and open work.
  • Local-first and $0 API cost: it runs on a Claude subscription, with a localhost-only API protected by origin/CSRF checks.
